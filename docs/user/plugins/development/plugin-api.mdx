Every plugin declares the oldest API level it requires with `plugin_api` in `plugin.toml`. API levels are cumulative: use the oldest level that includes every capability your plugin needs to keep it compatible with as many Nythera versions as possible.

<PluginApiTable />

Nythera currently supports plugin API levels <PluginApiRange />. A plugin version declaring a level outside that range cannot run.

Raising a plugin's level therefore drops it from every Nythera below it. A source repo can keep those users covered by publishing older revisions in its catalog: Nythera then installs the newest revision of the plugin its own API range allows, labels it in the store as an older version, and moves the user up to the newest one once they upgrade Nythera. See [keeping older Nythera versions supported](/nythera/plugins/development/workflow/#keeping-older-nythera-versions-supported).
