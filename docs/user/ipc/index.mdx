IPC commands let you control Nythera from a terminal, a compositor keybind, a script, or a hook.

All commands use this shape:

```sh
nythera msg <command>
```

For example:

```sh
nythera msg dock-toggle
nythera msg volume-up
nythera msg panel-toggle launcher
nythera msg screenshot-region
```

<Aside type="note">
  These pages list commands exactly as you run them. The same `nythera msg ...` form is used in terminals, compositor keybinds, hooks, hot-corner commands, and idle command fields.
</Aside>

## Compositor keybinds

A compositor keybind only needs to launch a Nythera command. The command part is compositor-agnostic:

```sh
nythera msg panel-toggle launcher
nythera msg panel-toggle control-center
nythera msg settings-toggle
nythera msg volume-up
```

Use your compositor's normal `exec`, `spawn`, or command-binding syntax to run those commands.

## Discovering commands

Not sure what else you can control? You can see all IPC commands via this terminal command:

```bash
nythera msg --help
```

## Using IPC in config

Config command fields run through the shell. Use the canonical IPC CLI when a command needs to call Nythera, and compose it with other shell commands when needed:

```toml
[idle.behavior.custom]
timeout = 660
action = "command"
command = "nythera msg session lock && notify-send 'Session locked'"

[hooks]
started = "nythera msg panel-toggle launcher"
```
