Nythera is a source-built personal fork. Packages published for Noctalia do not install this fork.

## Build

Clone [Kangy1103/noctalia](https://github.com/Kangy1103/noctalia), select `dev`, and follow the repository's [BUILDING.md](https://github.com/Kangy1103/noctalia/blob/dev/BUILDING.md) for dependencies.

```sh
git clone --branch dev https://github.com/Kangy1103/noctalia.git nythera-shell
cd nythera-shell
just build
```

The daily/development executable is `build-debug/nythera`. The default development build retains debug information with optimisation enabled.

## Install and run

```sh
just install debug
nythera --daemon
nythera msg status
```

Installation uses the configured prefix (default `/usr/local`), which must be writable by the installer. See PACKAGING.md for a staged install and complete asset layout. Application data uses the standard XDG roots under `nythera`; no Noctalia executable is required.

## Existing fork profile

Stop the old fork while unlocked, then deliberately copy its isolated profile:

```sh
nythera config migrate-legacy --include-keyring
```

This preserves originals and existing Nythera files. Packaged Noctalia is not automatically imported. Read [REBRAND.md](https://github.com/Kangy1103/noctalia/blob/dev/REBRAND.md) for explicit source selection, keyring handling and external integration contracts.
