Nythera's Nix package is provided by this repository's flake. The upstream Noctalia nixpkgs package and binary cache do not distribute the Nythera fork.

```sh
git clone --branch dev https://github.com/Kangy1103/noctalia.git nythera-shell
cd nythera-shell
nix build .#default
./result/bin/nythera --help
```

Use `nix develop` for the repository's development shell. The package installs `nythera`, its assets, desktop entries and shell completions. Integrating the flake into a system or Home Manager configuration remains a local deployment choice; Nythera does not alter compositor keybinds or autostart automatically.

Runtime services such as NetworkManager, Bluetooth, UPower, power profiles, PipeWire and a Secret Service provider must be available for their respective features. See BUILDING.md and PACKAGING.md for the dependency and runtime requirements.
