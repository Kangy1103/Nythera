:::tip[Method]
Use compositor autostart as the primary method.
:::

### Autostart by your Wayland compositor

This is the recommended method for launching nythera, as it integrates with your window manager.

For the *Umbriel* compositor, add `nythera` to the existing `autostart` array under `[general]` in `~/.config/umbriel/config.toml`. Preserve any commands already in the array:

```toml
[general]
autostart = ["nythera"]
```

For the *Niri* compositor, add the following line to the end of your configuration file, typically located at `~/.config/niri/config.kdl`

```ini
spawn-at-startup "nythera"
```

For the *Hyprland* compositor, append this to your existing `hyprland.start` event hook in your Lua configuration file, typically located at `~/.config/hypr/hyprland.lua`

```lua
hl.on("hyprland.start", function()
  hl.exec_cmd("nythera")
end)
```

If your compositor expects startup commands to return after the shell has initialized, run Nythera in daemon mode:

```bash
nythera --daemon
```

Daemon mode returns after the shell has initialized. The optional polkit authentication agent starts asynchronously after the UI is up.

---

### Manual Launch for Debugging

The most direct way to run Nythera for testing or debugging. Open a terminal and execute:

```bash
nythera
```

### Logs

Nythera writes its main log to `$XDG_CACHE_HOME/nythera/nythera.log`. If `XDG_CACHE_HOME` is unset, the fallback path is `~/.cache/nythera/nythera.log`. The previous file is retained as `nythera.log.1` when the current log reaches 1 MiB.

### Starting, stopping, and restarting Nythera

Run `nythera start` to launch the shell through the same startup path as `nythera`. Add `--daemon` when it should return after startup. Starting another instance while Nythera is already running reports an error.

Run `nythera stop` to gracefully stop the running shell, or `nythera restart` to stop and restart it. Restart preserves the current foreground or daemon mode and the single-instance lock. Stop and restart report an error if Nythera is not running.
