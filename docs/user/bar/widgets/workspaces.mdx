Workspace switcher with three styles: regular animated pills, minimal labels without pill backgrounds, or Focus Hint (small dots for inactive workspaces and an expanded active pill with the focused app icon).

Right-click the widget to open a schematic window map for its monitor. On Umbriel, the map uses a snapshot of reported window positions and sizes; click a rectangle to focus that exact window. Dismiss the compact map with Escape, an outside click, or its close button. Left-click workspace switching is unchanged. Each window has a separate top-right cross to request closing that exact window without focusing it. Click and drag the map in either direction to pan; dragging does not activate a window or its close control. Use the outward-arrows **Expand** icon to pop the same map into a normal desktop window, like Settings. The compositor manages its placement and native move/resize interactions; drag the header to move it and the corner grip to resize it. The expanded view uses a fixed monitor-relative miniature scale and retains window focus and close controls. Adding windows or workspaces grows the canvas rather than shrinking the rectangles. Drag any blank area or window tile to pan horizontally and vertically; extra canvas margins allow panning even when the map fits. The expanded window uses the same background and decoration conventions as Settings. Resizing reveals more or less of the same fixed-scale map; expanded dimensions are saved per output under `[workspace_map_expanded]`, separately from the compact panel’s placement and dimensions. The map reuses Window Inspector capture for low-rate live window previews. Snapshots fill the window rectangle at their original aspect ratio, with app identification and close controls overlaid instead of a separate title strip. A serial initial sweep quickly fills visible tiles, up to 320×200 pixels each; ongoing updates then share one capture slot and a maximum of four captures per second across the whole map. The oldest visible frame is updated next, so adding windows shares the budget instead of multiplying it. Slow capture paths back off further, failures wait five seconds before retrying, and unchanged frames skip texture uploads and map redraws. An 8 MiB snapshot-data budget bounds the per-map cache; unavailable captures or exhausted budget retain schematic tiles. Use the pause/play icon to stop or resume live updates; pausing still captures visible tiles that do not yet have a snapshot. Capturing pauses during map dragging and when the compositor reports the native window suspended. Closing the map cancels its capture and scheduler and releases cached images. Compositors without window geometry show an empty state.

The map defaults to an attached panel and follows its bar's layer and attached styling. **Settings → Panels → Window Map** provides Placement, Position and Open near click controls, matching other panels. TOML keys under `[shell.panel]` are `workspace_map_placement` (`"attached"` or `"floating"`), `workspace_map_position` and `open_near_click_workspace_map`. Floating maps use the shared `floating_layer` setting.

Panel size is remembered separately for each output connector in `state.toml` under `[workspace_map]`. New profiles derive their initial dimensions from the output's aspect ratio and estimated workspace content, capped to fit the screen. A saved size overrides that default only for its own output. The previous global size is retained in the state file but is not applied to every new output profile. Drag the small corner grip to resize the panel; the grip follows the free corner when attached to a bottom or right bar. Resizing reveals more or less of the same canvas without changing window scale or proportions.

The workspace boundary and windows share one scale, preserving positions, proportions and gaps. On Umbriel, the boundary uses the compositor's usable area, excluding top, side and other reserved bars; ordinary tiling gaps inside that area remain visible. It is shown only in the workspace currently visible on that output. Other compositors fall back to the full output when work-area metadata is unavailable. Scrolling columns beyond the boundary remain visible in the map; wholly off-screen windows are dimmed. Portrait maps scale to a readable width so vertically stacked windows do not become tiny. The focused window has an accent fill and border. Window headings pair application icons with short application names; hover for full window titles. Very small rectangles keep their proportions, showing an icon alone or relying on the tooltip when space is insufficient. Equally sized windows reported by the compositor remain equally sized in the schematic.

Every workspace reported on that monitor appears in the same compact overview, including inactive and empty workspaces. A small, consistent gutter separates workspace geometry without labels or heading dividers. Inactive empty workspaces retain a compact blank area instead of reserving a whole monitor-sized row. All workspaces share a readable scale and origin. Extra columns extend the canvas instead of shrinking the windows; use horizontal scrolling or the bottom scrollbar to reach them. The overview initially centres the workspace area. Vertical scrolling remains available for further workspaces. Equally sized windows remain comparable across workspaces. Clicking a window on an inactive workspace focuses it through the same exact-window action.

On portrait outputs, workspaces sit beside one another from left to right. Vertically stacked windows remain stacked inside their own workspace; horizontal scrolling reaches the neighbouring workspaces. Landscape outputs retain the existing workspace rows.

Labels are controlled by two independent settings: `show_labels` turns them on or off, and `label_source` picks what they say. With `show_labels = false`, regular draws unlabeled pills and Focus Hint shows just the focused app icon. Minimal draws no pill backgrounds at all, so its workspaces become blank slots. Focus Hint's app icon has its own switch, `show_icons`; turning both off leaves an empty expanded pill for the active workspace.

Hovering a named workspace shows its full name in a tooltip whenever the pill does not already spell it out: when `max_label_chars` cut it short, when `label_source = "id"` shows a number instead, or when labels are off. Set the shared widget setting `show_tooltip = false` to turn this off (see [Bar → Per-widget overrides](/nythera/bar/#per-widget-overrides)).

Workspace pills use the workspaces widget's resolved `capsule_radius`. Set `[widget.workspaces].capsule_radius` for just the workspace switcher, or `[bar.<name>].capsule_radius` as the bar default. Pill styling and `capsule_radius` apply only when `style = "regular"`.

| Setting                     | Type   | Default       | Description                                                                                                                                                                                                                                                                        |
| --------------------------- | ------ | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `style`                     | string | `"regular"`   | Pill style: `"regular"` (animated pills), `"minimal"` (labels drawn without pill backgrounds, colored with the focused, occupied, empty, and urgent colors), or `"focus_hint"` (inactive dots + expanded active pill with focused app icon).                                       |
| `show_labels`               | bool   | `true`        | Draw text labels on workspaces. Minimal renders labels and nothing else, so turning them off leaves its workspaces as empty slots.                                                                                                                                                 |
| `show_icons`                | bool   | `true`        | Draw the focused app icon on the active pill. Focus Hint only; the other styles never draw app icons.                                                                                                                                                                              |
| `label_source`              | string | `"id"`        | What labels show: `"id"` (workspace number, falling back to its name when no numeric identity exists) or `"name"` (workspace name).                                                                                                                                                |
| `max_label_chars`           | int    | `1`           | Maximum characters for non-numeric workspace labels, including names used as the `"id"` fallback. Numeric labels such as `10` and `11` are never truncated.                                                                                                                        |
| `pill_scale`                | float  | `1.0`         | Scale workspace pill thickness (cross-axis size; regular style only).                                                                                                                                                                                                              |
| `active_pill_size`          | float  | `2.2`         | Minimum active pill length along the bar, as a multiple of pill thickness. Labels may expand beyond this.                                                                                                                                                                          |
| `inactive_pill_size`        | float  | `1.0`         | Minimum inactive pill length along the bar, as a multiple of pill thickness. Labels may expand beyond this.                                                                                                                                                                        |
| `focused_color`             | string | `"primary"`   | Color role or hex color for the focused workspace pill                                                                                                                                                                                                                             |
| `occupied_color`            | string | `"secondary"` | Color role or hex color for occupied (non-focused) workspace pills                                                                                                                                                                                                                 |
| `empty_color`               | string | `"secondary"` | Color role or hex color for empty workspace pills                                                                                                                                                                                                                                  |
| `urgent_color`              | string | `"error"`     | Color role or hex color for urgent workspace pills                                                                                                                                                                                                                                 |
| `change_color_on_hover`     | bool   | `true`        | Use the theme's hover colors while the pointer hovers over a workspace. Minimal style changes the label to the `hover` color; the other styles use `hover` for the fill and `on_hover` for the label. Set to `false` to preserve each workspace's configured color while hovering. |
| `focused_output_only`       | bool   | `false`       | Only highlight the active workspace on the monitor that has keyboard or pointer focus; other monitors show their active workspace in the occupied color.                                                                                                                           |
| `labels_only_when_occupied` | bool   | `false`       | Show labels on workspaces with open windows and on the active workspace even when empty; other empty tags stay unlabeled. Requires `show_labels = true`, and does not apply to `focus_hint`, which only ever labels the focused workspace.                                         |
| `hide_when_empty`           | bool   | `false`       | Hide workspace pills with no open windows.                                                                                                                                                                                                                                         |
| `show_all_outputs`          | bool   | `false`       | Show workspaces from every monitor. The bar's own monitor is listed first.                                                                                                                                                                                                         |

On labwc, the compositor does not report which workspace a window is on, so occupancy (`hide_when_empty`, occupied colors, and Smart auto-hide) is inferred. The focused window is assigned to the active workspace, other windows keep their last known workspace, and a new window is assumed to be on the active workspace. Windows that were already open on another workspace when the shell started count as being on the active workspace until you focus them.

```toml
[widget.workspaces]
style = "regular"       # regular | minimal | focus_hint
show_labels = true      # false = unlabeled pills (Focus Hint: app icon only)
show_icons = true       # focus_hint only; false = active pill without the focused app icon
label_source = "id"     # id | name
max_label_chars = 2     # truncate long workspace names (e.g. "VESKTOP" → "VE")
show_tooltip = true     # false = no full-name tooltip on hover
labels_only_when_occupied = true  # (1) (2*) ( ) (4) - occupied tags and the active tag show labels (*active but empty)
hide_when_empty = true
show_all_outputs = false  # true = include workspaces from every monitor; this bar's monitor comes first
pill_scale = 1.0
active_pill_size = 2.2
inactive_pill_size = 1.0
focused_color = "primary"
occupied_color = "secondary"
empty_color = "surface_container"
urgent_color = "error"
change_color_on_hover = true  # false = keep configured workspace colors while hovering
focused_output_only = false  # true = only the focused monitor highlights its active workspace
```
