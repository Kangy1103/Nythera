Emacs can be themed using the Nythera color scheme through the built-in theme system.

## Setup

1. **Enable Emacs theming in Nythera:**

- Open **Settings → Color Scheme → Templates → Programs**
- Toggle on **Emacs**

2. **Add the theme to your Emacs configuration:** Add the following line to your Emacs configuration file (typically `~/.emacs.d/config.el`, or `~/.config/doom/config.el`):

   ```elisp
   (load-theme 'nythera t)
   ```

   The `t` argument enables the theme immediately and disables any previously active themes.

:::note
If you get an error saying `nythera-theme` can't be found, you may need to add the themes directory to your load path before loading the theme. The exact path may vary depending on your Emacs configuration:

```elisp
(add-to-list 'custom-theme-load-path "~/.config/emacs/themes/")
(load-theme 'nythera t)
```
:::

3. **Reload your configuration:**

- Restart Emacs, or
- Evaluate the expression: `M-x eval-buffer` or `C-x C-e` after the line

## Configuration Example

Here's a complete example of how to add it to your `config.el`:

```elisp
;; Load Nythera theme
(load-theme 'nythera t)
```

You can also add it conditionally or after other configurations:

```elisp
;; Load Nythera theme after startup
(add-hook 'after-init-hook (lambda () (load-theme 'nythera t)))
```

## Troubleshooting

- **Theme not found:** Ensure that Emacs theming is enabled in Nythera settings and that the theme files are being generated correctly. If the files exist but aren't found, add `(add-to-list 'custom-theme-load-path "~/.config/emacs/themes/")` before `(load-theme 'nythera t)`.
- **Theme not applying:** Make sure you've added `(load-theme 'nythera t)` to your Emacs configuration file
- **Colors not updating:** Restart Emacs or reload your configuration after changing color schemes in Nythera
- **Theme conflicts:** The `t` argument in `load-theme` disables other themes. If you want to keep other themes, you may need to adjust your configuration

## Additional Notes

The Nythera theme for Emacs integrates with Nythera's color scheme system. When you change color schemes in Nythera, the Emacs theme will be regenerated to match. You'll need to reload the theme in Emacs to see the changes:

```elisp
(load-theme 'nythera t)
```

Or use `M-x load-theme` and select `nythera` from the list.
