# Scarlet Protocol — ChatGPT

`Scarlet-Protocol-ChatGPT.user.css` is a browser user style adapted from Nythera's `Scarlet-Protocol.json` palette.

## ChatGPT website

Install the CSS with the Stylus browser extension, then open the style in Stylus and save it. The style is scoped to `chatgpt.com`; disable or remove it in Stylus to return to ChatGPT's normal appearance. It is a user style, not an official ChatGPT theme, and selectors may need adjustment if the site changes its markup.

## ChatGPT desktop app

The CSS file cannot be installed into the ChatGPT desktop app through its supported settings. For a close built-in match, set **Settings → General → Appearance → Dark** and choose **Pink** under **Accent color**. ChatGPT currently does not offer a custom hex accent setting, so the exact Scarlet Protocol red is available only in the browser with a user-style extension.
